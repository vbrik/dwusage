# Live Systems
- Never copy real user names, host names, or paths that identify people from live systems
  into files that may be committed (docs, tests, fixtures, examples). Use placeholders such
  as `<user-a>`; anonymize captured fixtures.
- Before drawing a conclusion from live data, rule out permission errors, unreadable or
  vanished entries, and fields you did not check (e.g. mtime as well as ctime).
